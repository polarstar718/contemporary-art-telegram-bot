# 🏛️ 동시대 현대미술 큐레이션 텔레그램 봇 (Contemporary Art Bot)

세계적인 권위의 비엔날레(베니스, 카셀 등)와 아트페어(아트바젤, 프리즈), 주요 현대미술상(터너상, 황금사자상 등)에서 공인된 **동시대 현대 미술가(Contemporary Artists)**의 작품관, 특징, 실제 고화질 작품 사진(10~30점), 공식 SNS 및 출처를 **매일 주중(월~금) 오전 08:00 (KST)**에 텔레그램으로 배달해 주는 프리미엄 도슨트 봇 서비스입니다.

---

## ✨ 핵심 기능 및 특징

1. **엄격하고 신뢰도 높은 작가 큐레이션 풀 (총 20인 거장, 총 202점 작품)**
   - **설치미술, 공간 예술, 미디어아트 75~80% 집중 편성** (주 3~4회)
   - **동시대 혁신 회화, 사진, 개념 조각 20~25% 균형 편성** (주 1~2회)
   - 전원 베니스 비엔날레(황금사자상/특별상), 터너상 수상자 또는 세계 최고 권위 기관 회고전 작가
2. **친절한 한국어 도슨트 & 글로벌 원문 병기**
   - 100% 매끄럽고 편안한 한국어 도슨트 톤으로 작가의 철학(작품관)과 시각적 특징을 해설
   - 작가명, 작품명, 갤러리명, 소장처는 **영문 원문을 함께 병기**하여 인스타그램 및 웹 검색 편의 극대화
   - 인스타그램 공식 계정, 웹사이트, 주요 소장처(테이트, MoMA, 구겐하임, 국립현대미술관 등) 링크 제공
3. **텔레그램 최적화 10~30점 도록 감상 UX (Inline Button)**
   - 1회 전송 시 **작가 해설 카드 + 대표작 10점 앨범(Media Group)** 전송
   - 메시지 하단의 **[🖼️ 추가 작품 10점 더 보기 (11~20번)]** 버튼을 누르면 다음 10점씩 순차적으로 펼쳐져 대량의 이미지가 채팅방을 어지럽히지 않고 쾌적하게 감상 가능
4. **정기 알림 & 상시 즉시 실행 명령어**
   - **정기 발송:** 매주 월요일 ~ 금요일 오전 08:00 (한국 시간 KST) 자동 브로드캐스트
   - **즉시 조회:** `/today` (오늘의 작가 즉시 보기), `/random` (무작위 작가 탐색), `/list` (전체 작가 풀 조회)

## 🚀 빠른 시작 가이드 (Quick Start)

### 1단계: 텔레그램 봇 토큰 발급 (1분 소요)
1. 텔레그램 앱에서 **[@BotFather](https://t.me/BotFather)** 를 검색하여 대화를 시작합니다.
2. `/newbot` 명령어를 입력합니다.
3. 봇의 표시 이름(예: `Contemporary Art Docent`)과 사용자명(예: `my_modern_art_bot`, 끝이 `bot`으로 끝나야 함)을 순서대로 입력합니다.
4. 생성이 완료되면 제공되는 **HTTP API 토큰** (예: `7123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`)을 복사합니다.

### 2단계: 환경 설정 (.env)
`contemporary_art_bot/.env` 파일을 메모장이나 VSCode로 열고 발급받은 토큰을 입력합니다:

```env
# 1단계에서 발급받은 봇 토큰 입력
TELEGRAM_BOT_TOKEN=7123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

# [선택] 본인의 Chat ID (미입력해도 봇에게 /start 를 누르면 자동 등록됩니다)
TELEGRAM_CHAT_ID=

# 매일 주중 발송 시각 (기본값: 한국 시간 오전 8시 00분)
DELIVERY_HOUR=8
DELIVERY_MINUTE=0
TIMEZONE=Asia/Seoul
```

> **💡 본인의 Chat ID를 미리 알고 싶다면?**
> 텔레그램에서 **[@userinfobot](https://t.me/userinfobot)** 에게 아무 메시지나 보내면 즉시 본인의 `Id` 번호(예: `123456789`)를 알려줍니다. (미입력해도 상관없습니다!)

### 3단계: 로컬 PC에서 봇 실행
터미널(PowerShell 또는 명령 프롬프트)에서 아래 명령어를 실행합니다:

```bash
cd "c:\Users\polar\OneDrive\바탕 화면\최광민\AI\contemporary_art_bot"
python bot.py
```

실행 후 텔레그램에서 생성한 본인의 봇을 열고 **`/start`** 버튼을 누르면 완료됩니다!

## 📱 텔레그램 봇 명령어 일람

| 명령어 | 설명 |
|:---|:---|
| `/start` | 봇 시작, 안내 메시지 출력 및 매일 오전 8시 수신 채팅방으로 자동 등록 |
| `/today` | 기다리지 않고 **오늘 선정된 현대미술 작가와 작품 10~30점 즉시 감상** |
| `/random` | 아카이브에 수록된 20인의 거장 중 무작위 1인을 뽑아 즉시 감상 |
| `/list` | 20인 작가 풀의 장르(설치/미디어 vs 회화/사진) 및 소개 상태 전체 조회 |
| `/status` | 현재 한국 시각, 주중 여부, 구독자 수 및 봇 정상 가동 상태 확인 |
| `/subscribe` | 매일 아침 08:00 자동 알림 수신 재등록 |
| `/unsubscribe` | 매일 아침 08:00 자동 알림 수신 해제 |
| `/help` | 사용법 및 도움말 보기 |

## ☁️ PC를 켜지 않아도 24시간 365일 작동하는 무료 클라우드 배포 (선택)

개인 PC를 끄더라도 봇이 매일 오전 8시에 정상 발송하고 버튼 클릭에 반응하도록 하려면, 무료 클라우드 서비스(예: [Render.com](https://render.com))에 3분 만에 무료 배포할 수 있습니다. 이미 모든 배포 설정 파일(`Dockerfile`, `Procfile`, `render.yaml`, `requirements.txt`)이 프로젝트에 포함되어 있습니다.

### Render.com 무료 배포 방법:
1. 본 프로젝트 폴더를 본인의 GitHub 저장소에 푸시(업로드)합니다.
2. [Render.com](https://render.com)에 로그인 후 **New +** -> **Background Worker** 를 클릭합니다.
3. GitHub 저장소를 연결합니다.
4. 설정값:
   - **Environment:** `Python`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
5. **Environment Variables**에 아래 1개 항목을 추가합니다:
   - Key: `TELEGRAM_BOT_TOKEN` / Value: `본인의 텔레그램 봇 토큰`
6. **Create Background Worker** 버튼을 누르면 배포 완료! 이제 PC를 꺼도 365일 24시간 작동합니다.
